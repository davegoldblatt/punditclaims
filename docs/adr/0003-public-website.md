# 0003 The public website

Date: 2026-10-28. Tickets: DAV-415, DAV-416, DAV-417, DAV-418, DAV-419, DAV-420 (reader side), DAV-421.

1. Every page, count, export, feed, sitemap entry, search record, and share image reads `release()` from `src/lib/published.ts`. Wording the policy does not define (provider names, access states, evidence relations, topic labels) lives once in `src/lib/view.ts`. `/method` also reads `policy/policy.yaml` for the list of policy versions, because the release does not carry that history.
2. `scripts/check-dist.ts` runs after Pagefind in `npm run build`. It recomputes every expected value from the manifest instead of calling the page helpers, so a page bug cannot hide itself. Each count on a page carries `data-count` (a key) and `data-n` (the number); the check compares both and checks that the visible text shows the number. Negative controls (a tampered count, a missing page, a dropped row, a missing index entry, a duplicate feed item, a stale page, fixture output checked as production) were run once by hand and each failed the check.
3. Two typefaces with a meaning: Libre Caslon Text sets only words quoted from a source; Public Sans sets everything the site wrote. Three self-hosted, subset faces in total (about 45 KB). One accent colour. Every outcome label has the same style, so the word carries the meaning and no outcome looks like a failure badge.
4. The register lists live claims only, so its counts equal the manifest's `distinct_claims`. Withdrawn claims are listed apart, below the register, and keep their pages as tombstones. A withdrawn claim's excerpt sits behind a disclosure, because a withdrawal can mean the quotation did not match the source.
5. Filters live in the query string (`person`, `outcome`, `kind`, `horizon`, `topic`, `sort`, `q`). Unknown values are switched off with a visible note. Search inside the register uses the Pagefind index; when the index is missing (development) it falls back to matching row text. Without JavaScript the filters stay hidden and every row shows in the default order.
6. "Due" and "deadline passed" come from `review.horizon_now` and are always shown with the release's `reference_date`. No page reads the visitor's clock.
7. Pages are indexable only when `PC_SITE_ORIGIN` is set explicitly, the build is not a fixture, and a release exists. Otherwise every page carries `noindex` and `robots.txt` disallows everything. Fixture builds also carry a visible "Synthetic preview" band and a share-image badge.
8. The repository URL for disputes is `SITE.repo` in `src/site.ts`, a placeholder until the public repository exists. The private contact route is `PRIVATE_CONTACT`, `null` until decided; pages then say an address will be listed before launch.
9. Not built, by decision: date-selected historical views, `/llms.txt`, per-record held pages, a theme toggle.
